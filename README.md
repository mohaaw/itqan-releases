# ITQAN Releases

Public APK host for the ITQAN Android in-app updater.

## 1.7.7 (v1.7.7)

| Variant | ABI | File |
|---------|-----|------|
| New devices | arm64-v8a | `itqan-1.7.7-new-devices-arm64-v8a.apk` |
| Old devices | armeabi-v7a | `itqan-1.7.7-old-devices-armeabi-v7a.apk` |
| Emulators | x86_64 | `itqan-1.7.7-emulators-x86_64.apk` |

The in-app updater picks the APK matching the device CPU (or the universal
fallback). Release notes: see the GitHub Release description.
